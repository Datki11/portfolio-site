Job Search Automation

Privacy policy

Effective October 26, 2026. Job Search Automation is a personal tool operated by Daniel Atkinson for his own job search.

Google data access and purpose

The desktop application uses Google's official OAuth process and the Gmail read-only scope (gmail.readonly). This scope permits reading the authorized mailbox; the application limits its retrieval queries to job-alert messages. It reads message bodies temporarily to extract job links and available job titles. It does not send, delete or modify mail, change labels, or mark messages read.

Local storage and protection

OAuth refresh tokens are stored in the operating system credential store (macOS Keychain on the owner's Mac). Downloaded OAuth client configuration stays in a private local folder. The application stores email message IDs, the mailbox identifier, message receipt times, source identifiers, extracted job information, processing metrics and sanitized errors in a local SQLite database. Full email bodies and recipient-specific tracking parameters are not retained in the database or logs. Data remains until the owner deletes it.

Sharing and use limitations

The current Gmail ingestion component does not send email bodies or Gmail credentials to Notion, OpenAI, advertisers, or other third parties. It communicates with Google to authorize and retrieve messages. This information website does not receive mailbox data or OAuth tokens. Google user data is not sold, used for advertising, or used to develop, improve or train generalized AI or machine-learning models.

Job Search Automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. If future features introduce additional data uses, this policy and the application's notices will be updated before those features are enabled.

Control, revocation and deletion

The owner can revoke access through Google Account connections, remove the app's entry from the operating system credential store, and delete the local SQLite database, reports and downloaded client configuration. Revoking access stops future authorized mailbox retrieval; deleting local files removes retained local data. The owner controls any backups separately.

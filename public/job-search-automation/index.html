Job Search Automation

A private, personal job-discovery tool operated by Daniel Atkinson. It reads job-alert emails from the owner's Gmail account, extracts individual job links, and organizes discovered openings in a local database for review.

The desktop application requests Google's read-only Gmail permission through Google's authorization flow. It does not send, modify or delete email, automate LinkedIn browsing, or submit job applications. This website provides information about the tool; mailbox access happens only in the owner's local application.

The tool is for the owner's use and is not offered as a public email service. No Gmail sign-in or mailbox data is collected by this website.
